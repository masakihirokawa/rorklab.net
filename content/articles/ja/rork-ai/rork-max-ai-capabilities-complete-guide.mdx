Rork Max を使って最初に驚いたのは、SwiftUI のコードが「動くレベル」で出てくることでした。

「AI がアプリを作る」というフレーズは大げさに聞こえますが、Rork Max が生成するネイティブコードは、これまでのノーコードツールとは明らかに異なるレベルです。この記事では、Rork Max の AI 機能の中身と、実際のアプリ開発にどう活かせるかを整理します。

## Rork Max が他のプランと違う理由

Rork の無料プランや標準プランでは、プロトタイプレベルのコードが生成されます。Rork Max は、その背後で動くモデルが異なります。

Rork Max では Claude Opus 4 が推論エンジンとして使われており、より複雑な UI ロジック、状態管理、API 連携のコードを正確に生成できます。単純な画面よりも「複数の状態を持つインタラクティブな UI」や「バックエンドと連携するデータフロー」のような複雑なコードで、その差が顕著に出ます。

## SwiftUI ネイティブアプリ生成の実力

Rork Max が最も得意とするのが、iOS ネイティブアプリの SwiftUI コード生成です。

**生成が得意なコンポーネント**
- リスト表示とナビゲーション（NavigationStack 対応）
- フォームバリデーション付きの入力画面
- SwiftUI の状態管理（@State、@ObservedObject、@EnvironmentObject）
- カスタムアニメーションとトランジション
- Core Data を使ったデータ永続化

実際のプロンプトと生成コードの関係を見ると、「詳しく書けば書くほど精度が上がる」という傾向があります。

**高精度な生成のためのプロンプト例：**

```
ユーザーが日々の支出を記録できるiOSアプリを作ってください。
- カテゴリ（食費・交通費・娯楽など）を選択できる
- 金額と日付を入力できる
- 月ごとの合計を表示する
- Core Dataでデータを保存する
- SwiftUIとiOS 17以上を前提にする
```

このような具体的な要件を書くと、Rork Max は NavigationStack、Form、CoreData の永続化ロジックを含む、そのまま動作する SwiftUI コードを生成します。

## React Native と Expo への対応

iOS だけでなく、Android を含むクロスプラットフォーム開発にも対応しています。Rork Max は React Native と Expo のコードも生成できます。

React Native での生成が得意なパターン：

**FlatList とカスタムレンダリング**
```
商品一覧を表示するReact Nativeアプリを作ってください。
- APIからデータを取得してFlatListで表示
- 各アイテムには画像・タイトル・価格を表示
- タップで詳細画面に遷移
- ローディング状態とエラー状態を表示
```

このプロンプトから、TypeScript 型付きの完全な実装コードが生成されます。`useEffect` での API 取得、`useState` での状態管理、`react-navigation` を使った画面遷移まで含まれます。

## AI 機能の実践的な使い方

Rork Max の AI 機能を効果的に使うためのコツがいくつかあります。

**イテレーションを前提にした使い方**

1回のプロンプトで完璧なアプリを作ろうとするより、「大まかな構造を作る → 細部を修正する」という2段階のアプローチが効率的です。最初のプロンプトでアーキテクチャを確定させ、その後に詳細を追加していく方法です。

**具体的な技術スタックを指定する**

「アプリを作って」より「SwiftUI + Combine + MVVM パターンでアプリを作って」の方が、意図した設計に近いコードが生成されます。使い慣れた技術スタックを明示することで、後から大幅に書き直す必要がなくなります。

**エラーが出たらエラーメッセージをそのまま貼る**

生成されたコードをビルドしてエラーが出た場合、エラーメッセージをそのままチャットに貼って「このエラーを修正してください」と伝えるだけで、ほとんどの場合修正されます。これは Rork Max のコンテキスト理解能力の高さが活きるシーンです。

## マルチエージェント連携の可能性

Rork Max は単独のコード生成だけでなく、複数の AI エージェントを組み合わせたワークフローへの統合も視野に入ってきています。バックエンド設計を Claude Code で行い、フロントエンドの UI 実装を Rork Max に任せるという分業パターンは、特に個人開発者にとって実用的です。

1人で iOS アプリをフルスタックで作るとき、「ビジネスロジックとデータ設計は自分でレビューしながらコーディング、UIの実装は Rork Max に任せる」という役割分担が、品質と速度のバランスを取りやすいと感じています。

## まずプロトタイプを動かしてみる

Rork Max の AI 機能の真価は、使ってみないと伝わりにくいです。まずは手元のアイデアで簡単なアプリのプロトタイプを作ってみてください。「こういうアプリが作りたいけど実装方法がわからない」というアイデアが、想像より早く形になる体験ができると思います。
