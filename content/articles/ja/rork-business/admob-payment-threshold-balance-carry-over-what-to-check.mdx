アプリに広告を載せて3か月。AdMobの画面には「推定収益 2,300円」と出ているのに、銀行口座には何も入っていません。

こうなると、多くの方が最初に思うのは「このまま届かなければ、残高は消えるのではないか」という不安だと思います。個人開発の小さなアプリほど、この疑問は起きやすいものです。思い込みで判断せず、Googleのヘルプに書かれている内容だけを根拠に整理します。

## 結論：基準額に届かない月の残高は、翌月に持ち越されます

AdMobのヘルプには、収益が基準額に届かなかった場合について、翌月の収益と合算される旨が書かれています。ですから、届かない月が続いても、その月ごとに残高が消えることはありません。

日本円で報告しているアカウントの場合、支払い基準額は **8,000円** です（USDのアカウントなら100ドル）。基準額は、アカウントの報告通貨ごとに決まっています。

ここで一点、注意が要ります。基準額の判定に使われるのは、画面に出る推定収益ではなく、**「お支払い」ページに記録されている確定済みの金額**です。ヘルプにも「すべてのしきい値は、推定収益ではなくお支払い履歴ページに基づく」という趣旨の記載があります。

「推定収益が8,000円を超えたのに入金されない」という場面の多くは、この差で説明できます。

## 支払いが実行されるまでの流れ

支払いは月次で、日付の目安はヘルプに次のように書かれています。

<table>
<thead>
<tr><th>時期</th><th>起きること</th></tr>
</thead>
<tbody>
<tr><td>毎月3日</td><td>前月分の収益が確定します</td></tr>
<tr><td>毎月20日</td><td>この日の残高が基準額に達していることが条件です</td></tr>
<tr><td>毎月21日前後</td><td>条件を満たし、支払い保留がなければ支払いが実行されます</td></tr>
</tbody>
</table>

日付は「おおむね」の扱いで、支払い方法によって前後することがあります。私自身は、20日時点の残高と保留の有無だけを月に一度見れば足りると考えています。

## 基準額を超えても入金されないとき、確認する3つの画面

残高が基準額を超えているのに入金がない場合は、次の3点を順に見ます。

**1. 住所確認（PIN）が済んでいるか。** 支払いを受けるには、郵送されるPINをAdMobに入力して住所を確認する必要があります。ヘルプによれば、PINの発行から4か月以内に完了しなければなりません。ハガキが届いたまま机に置いてある、という状況が意外とあります。

**2. 支払い保留がかかっていないか。** 20日に保留があると、その月は支払われません。保留を解除すると、数日以内に支払いが実行されると書かれています。保留の原因は、受け取りに必要な情報の未入力、支払い方法の未設定、本人確認の未完了などです。

**3. 支払い方法と、求められている追加情報が設定済みか。** 地域によっては、受け取りに必要な追加情報の入力が求められます。ここが抜けていると、残高があっても処理が止まります。

3つとも「お支払い」関連の設定画面で確認でき、どれも広告の配信量とは関係がありません。

## 本当に注意したいのは、残高ではなく「配信が止まったアカウント」です

繰り越しは保証されていても、アカウント自体が無効になると話が変わります。ヘルプには、**6か月間広告を配信しないとAdMobアカウントは無効化される**と書かれています。

無効化されたアカウントでも、再有効化の手続き（サインインして再承認を確認し、電話番号を認証する）を行えば、未払いの収益に再びアクセスできると案内されています。ただし、アプリが再び広告を配信するには、あらためて審査に出す必要があります。

また、アカウントを解約する場合に最終支払いを受けるには、解約基準額（日本円では1,000円）を超えていることに加えて、支払い方法・追加情報の入力・本人確認・住所確認が済んでいる必要があります。条件を満たさないまま解約すると、残りの収益は支払われないという確認が求められます。

私は、収益が小さいうちほどアプリを放置しがちだと思います。数か月で基準額に届く見込みが薄いアプリは、**6か月の無配信と解約時の条件**の2点だけ、頭に入れておくと安全です。

## 到達時期を見積もるスクリプト

「あと何か月で8,000円に届くのか」を見積もる、小さな計算です。月ごとの確定額を入れて使います。

```python
import math

THRESHOLD_JPY = 8000  # 日本円アカウントの支払い基準額（ヘルプ記載値）

def months_to_payout(confirmed_balance: int, monthly_earnings: int) -> int:
    """確定済み残高と、毎月の確定額から支払い開始までの月数を返す。"""
    if monthly_earnings <= 0:
        raise ValueError("毎月の確定額が0以下だと到達しません")
    remaining = max(THRESHOLD_JPY - confirmed_balance, 0)
    return math.ceil(remaining / monthly_earnings)

# 確定残高 2,300円、毎月の確定額 600円の場合
print(months_to_payout(2300, 600))  # -> 10
```

この例では10か月かかります。**6か月の無配信で無効化される**期間と比べると、配信を続けていれば問題ありませんが、更新を止める判断をするなら、この数字を見てからにしたいところです。確定残高には、必ず「お支払い」ページの金額を使います。

## 次にやること

- AdMobの「お支払い」ページで、確定済みの残高と住所確認の状況を確認します
- PINが未入力なら、期限（発行から4か月）を手帳などに書いておきます
- 更新を止めるアプリがあれば、配信が6か月止まる日を先に決めておきます
